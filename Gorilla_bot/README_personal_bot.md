# Personal Telegram Bot (MVP)

Файл `personal_assistant_bot.py` — это заготовка под личного Telegram-бота с разделением доступа:

- `/ask` — публичный AI-ассистент (доступен всем)
- приватные функции по коду (`/access`):
  - автопостинг в каналы с разными темами
  - крипто-анализ (`/crypto`)
  - астрология (`/astro`)
  - нумерология (`/numerology`)
  - таро (`/tarot`)

## Нужен ли `.env`?

Да, удобнее использовать `.env`, чтобы не держать ключи в коде и не вводить `export` каждый раз.

Полный пример файла (`Gorilla_bot/.env`):

```env
BOT_TOKEN=1234567890:YOUR_TELEGRAM_BOT_TOKEN
OPENROUTER_API_KEY=sk-or-v1-your-openrouter-api-key
BOT_ACCESS_CODE=MyStrongPrivateCode2026
OPENROUTER_MODEL=openai/gpt-4o-mini
```


## Если видишь ошибку `BOT_TOKEN некорректный`

Это значит, что бот **запустился правильно**, но не получил валидный токен.

Проверь по шагам:

1. В файле `.env` строка должна быть ровно в таком формате:
   `BOT_TOKEN=123456789:AA...`
2. Не оставляй текст-заглушку `YOUR_TELEGRAM_BOT_TOKEN`.
3. Убедись, что `.env` лежит либо рядом со скриптом `personal_assistant_bot.py`, либо в текущей папке запуска.
4. Возьми новый токен у `@BotFather`, если сомневаешься в текущем.

## Если видишь ошибку `401 User not found` (OpenRouter)

Это значит, что проблема в `OPENROUTER_API_KEY` (неверный/просроченный ключ), а не в Telegram токене.

Что сделать:

1. Открой `.env`.
2. Проверь строку `OPENROUTER_API_KEY=...`.
3. Нужен реальный ключ OpenRouter формата `sk-or-v1-...`.
4. Перезапусти бота.

Теперь бот перехватывает эту ошибку и отдаёт понятное сообщение, без падения процесса.

## Как работает доступ

1. Пользователь пишет `/access`.
2. Вводит код.
3. После успешной проверки ему открываются приватные команды.

## Важно

- Чтобы бот мог постить в канал, добавь его администратором канала.
- В команде `/add_channel` указывай `chat_id` канала формата `-100...`.
- Для `/crypto` используется публичный API CoinGecko (id монеты: `bitcoin`, `ethereum`, `solana` и т.д.).

## Структура кода (разбито по файлам)

Да, так удобнее редактировать 👌 Теперь код разделён по модулям:

- `personal_assistant_bot.py` — точка входа, роутинг хендлеров.
- `personal_bot/config.py` — `.env`, конфиг и проверка токена.
- `personal_bot/storage.py` — работа с JSON-хранилищем пользователей.
- `personal_bot/services.py` — интеграции (OpenRouter/CoinGecko).
- `personal_bot/scheduler.py` — логика автопостинга и антидубликатов.
- `personal_bot/states.py` — FSM состояния.
- `personal_bot/ui.py` — кнопки и меню.

Можно дальше дробить и сильнее: `handlers/assistant.py`, `handlers/crypto.py`, `handlers/autopost.py` и т.д.
